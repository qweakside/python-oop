## Главное, что понял

- **Класс** — чертёж, **объект** — экземпляр чертежа.
- `self` — ссылка на конкретный объект, поэтому `self.mushrooms` у каждого свой.
- Всё, что объявлено в теле класса вне метода, — **атрибут класса**, общий на всех.
- Изменяемые значения (`list`, `dict`, `set`) всегда создаём в `__init__`.
- `__init__` — инициализатор, а не «конструктор»; вызывается автоматически при создании.
- `__str__` определяет, что увидит человек при `print(obj)`.

## Ловушка, на которой я попался

```python
class Collector:
    mushrooms = []          # ОДИН список на все объекты

    def __init__(self):
        pass                # список не создаётся заново

a = Collector()
b = Collector()
a.mushrooms.append("Лисичка")
print(b.mushrooms)          # ['Лисичка'] — неожиданно
```

Правильно:

```python
class Collector:
    def __init__(self):
        self.mushrooms = []
```
